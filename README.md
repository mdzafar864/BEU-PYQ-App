# 📖 About

**BEU PYQ App** is a modern and responsive Progressive Web Application (PWA) designed specifically for students of **Bihar Engineering University (BEU)**.

The platform provides easy access to **Previous Year Question Papers (PYQs)** organized by **branch**, **semester**, and **subject**, helping students prepare efficiently for university examinations.

---

# ✨ Features

- 📚 Branch-wise Question Papers
- 🎓 Semester-wise Organization
- 📄 Subject-wise PDFs
- 🔍 Easy Navigation
- ⚡ Fast Loading
- 📱 Mobile Friendly
- 💻 Desktop Compatible
- 🌐 Progressive Web App (PWA)
- 📥 One Click PDF Download
- 🎨 Clean Modern UI
- 🔄 Regular Updates
- 🚀 GitHub Pages Hosted
